# 联通每日自动签到

只处理普通每日签到，保留手动签到、凭据获取和最近结果入口。已有凭据继续使用，无需清空本地数据。

## 本次更新

插件引用的远程脚本增加20261014-1版本标记，更新插件后加载新版，避免旧脚本缓存继续处理新参数。脚本同时兼容插件对象参数和JSON字符串参数；在完成解析后识别定时模式。保留原签到时间、随机延迟等参数名称。

以前若入口参数未识别，可能几毫秒结束、不发送请求，也不更新最近结果。新版保存启动、等待、查询、签到、复查及结束状态；无法识别参数也会记录明确原因。启动日志包含版本2026-10-14.1、入口类型和参数形式，不包含参数原文或凭据。

## 设置

- 自动签到默认开启；关闭后仍可手动执行。
- 默认时间每天12:00（0 12 * * *），随机等待0–1200秒。最小、最大延迟均可设为0–2000的整数。
- 手动执行不随机等待。定时等待期间不持执行锁；等待结束后读取最新保存的凭据。
- 获取签到凭据默认关闭。需要更新时开启并进入联通每日签到页面，收到通知后关闭；今天已签到也可获取。

## 查看结果

“联通签到最近结果”只读取本地，不请求联通、不提交签到。如果当前任务仍在等待，会显示剩余等待秒数；任务停在某一阶段且没有结束记录，也会明确显示，不把旧结果当成本次完成。

- UNICOM_CHECKIN_ACCOUNT_V1：登录与页面凭据，仅保留在本机，不要分享。
- UNICOM_CHECKIN_LAST_RESULT_V1：最近一次完成的手动或自动结果。
- UNICOM_CHECKIN_HISTORY_V1：最近20次完成结果。
- UNICOM_CHECKIN_LAST_RUN_V1：最近任务的启动、当前阶段与退出记录，可用于检查参数不识别、执行冲突或中断。
- UNICOM_CHECKIN_LOCK_V1：执行锁。
- UNICOM_CHECKIN_ATTEMPT_V1：当天提交保护。

先查询，今天已签则报告已签；未签到且状态明确才提交一次，再复查。失败原因会通知；网络异常或结果未确认不会自动重新提交。凭据不设置固定七天过期要求；有效性由接口实际返回决定。

当前普通日签已在手机成功验证；本次入口参数修正、阶段记录及等待时读取最新凭据已通过离线测试，未使用用户凭据发起签到请求。当前截图缺少12:00任务的详细输出，具体是旧缓存还是传参异常，需新版手机启动日志进一步确认。

安装：Plugins/unicom-checkin.plugin。更新时同时刷新插件及远程脚本；不用删除历史或重新获取仍有效的凭据。
