# 美团跳转任务助手

v0.3.0：在原11个入口上增加金猪、小美果园，共13项。一淘、中国移动停留10秒，其余5秒，再回美团等待2秒。闲鱼放在最后，并先转换为URL对象再打开；具体跳转效果仍需手机验证。

## 更新与使用

1. 在Loon更新原 `Plugins/meituan-jump.plugin` 和脚本，保留原来的本机配对码。订阅地址：`https://raw.githubusercontent.com/LazingLuo/LazingLuo_Loon-Rules/refs/heads/main/Plugins/meituan-jump.plugin`。
2. 添加私人安装包中的 `美团跳转任务-v0.3.0.shortcut`，替换旧快捷指令。已有配对码不变，无需添加本地规则或JS文件。
3. 保持Loon连接，打开美团金币任务列表。缺少链接时可手动进入对应任务一次，再运行快捷指令。记录有效期为24小时。
4. 首次跳转时允许系统打开目标App，运行时保持解锁，最后在美团查看奖励。

支付宝会员、金豆夺宝沿用原入口。新增读取原生小程序跳转中的 `tag.game` 任务资料。旧7项、11项快捷指令仍只收到其可执行的对应入口。

这次抓包没有恢复出美团小说的可靠链接；记录到的闲鱼跳转与旧版为同一路径，尚未证实另有独立闲鱼币入口，未编造额外链接。

脚本仅记录App已发送的任务链接，不调用接任务、完成或领奖接口。进入金猪、果园后如需游戏内操作，仍需自行完成。等待时长不表示服务器已确认完成。

任务链接、本机配对码、快捷指令和抓包不公开。公开文件仅含通用识别逻辑。检查：`node Tests/meituan-jump.test.cjs`；可附本机HAR路径进行离线核对，不发送账号请求。
