# 美团跳转任务助手（订阅版）

配套快捷指令依次访问：蚂蚁庄园、蚂蚁森林、淘宝芭芭农场、支付宝芭芭农场、一淘、中国移动、微博、闲鱼、支付宝会员、支付宝金豆夺宝、精彩内容，共11个入口。趣头条暂不加入。每个入口停留5秒，再回美团等待2秒。

## 安装

1. 在 Loon 的插件页面添加订阅地址：

   `https://raw.githubusercontent.com/LazingLuo/LazingLuo_Loon-Rules/refs/heads/main/Plugins/meituan-jump.plugin`
2. 打开插件设置，把私人安装包 `本机配对码.txt` 内的整行文字粘贴到“本机配对码”，保留中间的竖线。
3. 启用插件及 MitM，确认 Loon 证书已受信任；保存后断开并重新连接 Loon。
4. 从私人安装包添加已签名的 `美团跳转任务-v0.2.0.shortcut`。v0.2.0新增4项并将停留改为5秒，请换成这一版；原Loon插件和配对码保持不变。

只用这一种安装方式：无需导入本地JS、无需手工修改主配置。旧版若添加了3条美团本地规则，请禁用；旧插件也请禁用，避免同一请求重复匹配。仅删除旧的美团规则，保留其他插件。

## 使用

保持 Loon 连接，先在美团打开金币任务列表并停留几秒。Loon 记录到链接后会通知“已记录 x/11 项”。随后运行配套快捷指令；已有记录可在24小时内使用，缺少或过期的入口会跳过。可手动运行“查看美团任务记录”检查缺项。

运行时保持手机解锁，首次打开目标App时允许系统跳转。最后停在美团，查看金币到账情况。5秒是等待时间，实际是否完成由美团判断。

## 更新

识别逻辑和配套脚本通过 Loon 订阅维护；以后使用 Loon 的更新插件、更新脚本功能刷新即可。旧快捷指令仍只读取原7项，新增4项需更换为v0.2.0，改变快捷指令自身的入口数量、顺序或等待时间时仍需更换快捷指令。

任务链接只保存在手机 Loon 中。公开仓库包含通用脚本、空配对码插件、说明及离线检查；私人配对码、快捷指令、抓包和个人任务链接不公开。

本机读取地址 `example.com` 由 Loon 请求脚本直接回应，配套快捷指令先核对连通标记，再发送配对请求。插件已自带所需规则，无需另加 `DOMAIN`。

## 验证范围

扩展为11入口识别、24小时过期及账号切换处理，未新增接任务、完成或领奖接口。离线检查覆盖订阅脚本调用、配对、缓存和原请求放行。iPhone实际跳转和到账仍需手机验证。

仓库内检查方式：`node Tests/meituan-jump.test.cjs`。
