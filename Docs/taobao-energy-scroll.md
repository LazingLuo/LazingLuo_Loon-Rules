# 淘宝攒能量自动滚动（试用版）

配合“淘宝攒能量自动滚动试用版 v0.2.0”快捷指令，尝试省去搜索浏览及惊喜好物浏览页开始前的手动滑动。原手动版保持可用。

## 安装与首次测试

1. 在 Loon 安装并启用 `taobao-energy-scroll.plugin`。插件只增加 `mo.m.taobao.com` 的 MITM；现有证书需要已经安装并信任。插件不增加 DNS 拦截规则。
2. 导入已签名的 v0.2.0 快捷指令，在淘宝登录原账号。
3. 先选“单测搜索浏览”，保持屏幕解锁、淘宝在前台。首次跳转可能需允许打开淘宝。
4. 观察页面底部的辅助提示。出现“官方计时已启动”表示辅助脚本已观察到官方倒计时文字；仍须等待，并在返回活动后核对任务进度、能量。
5. 单测有效后可选“连续浏览3次”，依次搜索1次、惊喜好物2次。每页停留约45秒，连续进行约3分钟。快捷指令通知显示流程进度。

## 提示的含义

| 页面提示 | 含义 |
| --- | --- |
| 自动滚动准备中，等待任务提示 | 注入已执行，等待官方页面建立任务提示 |
| 已尝试滚动，等待官方计时 | 已尝试真实滚动，但尚未确认官方倒计时 |
| 官方计时已启动，请保持当前页面 | 已观察到官方“已浏览…秒”文字；不代表奖励已到账 |
| 官方页面显示已完成，请回活动核对 | 官方提示本任务已完成；可能是此前完成，不能算本次新增奖励 |
| 未能确认计时，请手动滑动一次 | 20秒内未观察到计时，可手动操作或停止快捷指令 |
| 已转为手动浏览，请看官方倒计时 | 用户触摸了页面，辅助脚本停止继续滚动 |

完全没有辅助提示时，可能是插件未执行、页面使用缓存、页面结构已变化或未成功解密。Loon 脚本任务日志可以区分“已注入”和“页面含安全策略，保持原响应”；日志不保存个人页面链接和任务参数。发现页面安全策略时不移除该策略，并通知本页需手动滑动。

## 工作范围

仅匹配这两个官方 HTTPS 页面，并且 URL 必须含快捷指令专用参数 `loon_energy_scroll=1` 及非空的 `ep`、`et`：

- `mo.m.taobao.com/union2/page_1728378489402`
- `mo.m.taobao.com/union2/page_1697972915627`

普通手动打开的页面不带专用参数，插件不会修改。插件等待官方浏览图标出现，再实际改变页面滚动位置；不合成触摸、点击或滚动事件，不修改官方计时，不直接调用任务提交接口，不读取或上传 Cookie、设备标识或页面参数。

在20秒内最多尝试6次滚动。页面不在前台时不滚动；离开页面或触摸页面后停止本页辅助。搜索及惊喜好物之外的任务不在此版本范围。链接沿用本人已有活动上下文，活动有效期、任务次数、任务接受状态及奖励由淘宝判断。

## 验证边界

这是试用版。离线响应范围检查以及本地浏览器测试用于检查注入、真实滚动和保存的官方代码的计时逻辑，不等于已在 iPhone 淘宝完成任务。原始任务数据与个人快捷指令不公开提交到仓库；仓库仅发布通用插件、脚本、离线检查和本文。

## 停用

在 Loon 关闭此插件，并使用原 v0.1.0 手动版即可。辅助脚本不会修改账户任务数据或持久化配置。
