# 京东活动

自用手动插件：京喜自营、东东农场、领券中心、家电家居、金融赚京豆、医药赚京豆。各一个执行入口，无定时。

农场不自动浇水，领券中心不自动砸蛋。金融赚京豆优先处理“逛超值爆款好物”，并处理同类普通浏览任务；每次提交后复查，只有次数增加、状态完成、任务从待办移除，或页面京豆按标明奖励增加时才确认。重复任务有进度或京豆增加才继续，单项最多29次。其他项目列在日志中，留在App处理。

金融首次使用：更新活动插件后，打开金融的“赚京豆”页面刷新。脚本复用本机同账号登录，另存此页面的设备和签名资料；不会覆盖签到凭据。正常只需刷新任务页；接取设备资料不足时可在App做一项普通浏览，再运行。日志列出确认次数和活动页面京豆增量，不估算未提供的奖励。金融执行版20261029-2补读任务副标题中的次数，并区分接取、提交、查询拒绝；拒绝后停止，不自动重试。

医药首次使用：更新京东开屏、签到和活动订阅，打开看病买药的任务列表刷新。手动运行“医药赚京豆”；处理普通定时浏览及每日签到，其他任务留在App。日志区分任务完成、接口明确发奖数量及京豆余额变化；不把标注奖励当成已到账。
