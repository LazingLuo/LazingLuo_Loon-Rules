# 京东活动（手动）

一个插件，五个手动入口，每个活动对应一个自包含脚本。没有定时项、自动执行、查询/只参与/只领奖/状态等额外菜单，也不提供“一键全部”活动队列。

| 入口 | 执行范围 |
| --- | --- |
| 京喜自营 | 沿用已修好的动态任务、计时、提交、领奖流程 |
| 东东农场 | 沿用任务与奖励流程，包含已适配的农场签到；不浇水，保留全部水滴 |
| 幸运转盘 | 沿用转盘任务，使用已有免费次数；逐次复查次数，保留已确认抽奖结果 |
| 天天砸金蛋 | 依据Faker的`jd_zjindan.js`：读取当前任务、签到/浏览、提交及复查，统计实际奖励返回 |
| 天天赚京豆 | 依据Faker的`jd_jrddzjd.js`：金融赚豆页任务、接取、跳转或计时后领奖；展示数量不作为到账数量 |

前三项直接使用仓库现有执行代码，只固定一个执行模式，原凭据、执行锁、当天提交记录和已验证抽奖保护均保留。后两项是新迁移实现，已核对公开脚本协议，尚需手机验证；不是已经确认真实账号可执行的结论。

## 使用与凭据

安装 `Plugins/jd-activities.plugin` 后，停用原京喜任务、农场/转盘任务插件，避免重复入口。原「京东合并签到」继续保留，签到菜单与定时不作调整。

把活动插件放在重叠凭据获取规则前面。活动插件的被动获取入口包含现有合并签到的解析，仍会刷新签到、京喜、农场和转盘等同账号本机资料。原来的开屏诊断若排在最前，会占用该域名的大范围响应规则；获取活动凭据时将活动插件放在它前面，或暂时停用开屏诊断。活动插件主动避开四个开屏配置functionId。

- 已获取的京喜、农场、转盘凭据直接复用，不需要清空重抓。
- 砸金蛋首次需要打开对应任务页刷新，金融赚京豆首次需要打开赚豆页面刷新；成功获取后通知一次，之后更新只记日志。没有完成的活动资料会明确提示，不向外部签名服务上传Cookie，也不自动做登录交换。
- 两项新活动使用本机 `JD_ACTIVITY_TASKS_ACCOUNT_V1`。砸金蛋可使用同账号更新的京东登录Cookie；金融保留金融活动自己的Cookie和设备资料。
- 当前签名适配基于已有5.3页面SDK环境。金融查询返回其他签名版本时保存版本提示并停止执行，需根据实际查询包继续适配，不会复用旧h5st、nonce或signature强行提交。

金融赚豆页面入口：`https://member.jr.jd.com/member/coinQuest/coin/`。仅提供页面位置，不在插件中自动打开或执行。

Faker的`jd_zjindan.js`当前文件名仍叫“天天砸金蛋”，实际查询走`interact_pre_executor`的`bargain/task_list`，项目ID为`3v5KsTzmzH4KqQCpjR3QQgrviq5k`，与9.9包邮任务体系有关。本版迁移这一实际流程，没有凭任务名称编造“砸蛋抽奖”接口，也不带入上游写死的首页任务ID。

## 执行结果

每项手动执行会处理支持的任务并领取相应奖励。分享、邀请、下单、关注、订阅等仍留给App；不购买抽奖机会、不消耗水滴。结果只统计领奖响应中可确认的京豆字段，任务宣传的“奖励N京豆”不算收入。未取得明确完成状态时显示“已提交，进度待App确认”。

新活动提交前写入当天记录，结果不明确时不自动重试相同提交。再次手动运行可以继续其他任务；不会因重复点击再次发起同一项有疑问的领取。各次请求更新临时API会话sdtoken，仅用于本轮同一主机，不覆盖持久登录凭据。

后两项没有真人账号联网测试；首次使用先查看日志。若提示签名版本不支持或接口拒绝，需要对应活动的真实请求响应才能继续定位，不能用离线检查通过替代手机成功。

## 文件与检查

插件：`Plugins/jd-activities.plugin`。五个执行脚本：`Scripts/jd-jxzy-activity.js`、`jd-farm-activity.js`、`jd-wheel-activity.js`、`jd-golden-egg.js`、`jd-earn-beans.js`。另有一个被动获取脚本 `Scripts/jd-activity-capture.js`，不会运行任务。

运行 `node Tests/jd-activities.test.cjs` 检查生成文件；源码目录另有 `build.py` 用于构建、`decode-static.py` 用于纯数据解码。公开发布仅包含通用脚本、插件、说明和检查，不包含上游原始研究资料、用户HAR或个人凭据。

验证记录：37项合并版离线检查通过；原农场79项与京喜23项回归检查通过；五个执行入口逐项通过Apple JavaScriptCore缺少凭据时的运行退出检查。签名检查使用模拟算法响应，未请求真实账号接口。
