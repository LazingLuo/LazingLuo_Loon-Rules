# 京喜自营任务（Loon 手动版）

在 Loon 手动运行，读取当前服务器任务列表，按要求计时后提交完成、领取并复查。没有定时任务，不依赖 Scriptable 或快捷指令。

## 安装和使用

远程版插件：`Plugins/jd-jxzy-tasks.plugin`；配套脚本：`Scripts/jd-jxzy-tasks.js`。发布后将插件链接导入 Loon。

安装链接：[京喜自营任务（手动）](https://raw.githubusercontent.com/LazingLuo/LazingLuo_Loon-Rules/refs/heads/main/Plugins/jd-jxzy-tasks.plugin?v=20261020-1)。在 Loon 中导入该插件即可，无需自行导入本地脚本文件。

共享凭据来自 `JXZY_CHECKIN_ACCOUNT_V1`，由现有“青龙任务接入”或“京喜自营每日签到”插件保存。新脚本只读取这份凭据，不修改，不向青龙发送凭据。缺失时在“青龙任务接入”开启“获取独立活动凭据”，在京东 App 进入京喜自营首页，待页面加载后返回 Loon。无需重新抓包或导入 HAR。

在 Loon 的手动脚本入口中使用以下名称：

- **京喜任务查询**：先运行一次，查看当前可处理的浏览任务和领取状态。
- **京喜任务执行并领取**：读取最新任务，逐项计时、提交、领奖和复查。
- **京喜任务只领取**：仅领取服务器已标记完成、尚未领奖的任务。
- **京喜任务最近结果与进度**：查询本机当前进度或上一轮结果。

日志会显示“第几项／共几项”、任务名称、剩余等待秒数、提交和复查阶段；结束后发一条通知。进度记录只在运行时更新，不另外设置通知定时任务。

## 执行边界

“浏览”采用脚本计时：不会打开 App、滚动或点击页面。平台要求额外浏览回调时可能不认可；完成、领奖均通过接口重新查询确认，失败即停止。本轮“领奖返回”和“已领状态复查确认”分开显示，不把累计余额当成本轮奖励。

处理当前列表中可识别的 `taskType=3` 浏览任务，包括视频、频道、农场入口等同类型任务；邀请助力、添加小组件等其他类型自动跳过。它不执行农场内部浇水、下单、授权或订阅。

执行与现有京喜签到互斥，凭据变化时停止。单轮预留约9分钟，过长任务停止后可再次手动运行。提交结果不明确时，当天不自动重复提交同一动作，请在 App 核对。任务执行记录与旧 Scriptable 版独立，请停用旧版本，避免同时执行。

接口来源和页面参数依据用户提供的 401／402 抓包及官方公开前端，使用同页已捕获的 Cookie、设备凭据和签名环境，动态生成本次签名。发布文件不包含个人 Cookie、抓包或账号信息。

## 验证

运行 `node Tests/jd-jxzy-tasks.test.cjs` 可离线验证完整发布脚本；网络全为模拟响应，包含官方签名 SDK、共享凭据读取、计时、任务状态变化、领奖复查、重复提交、凭据刷新和进度检查。实际 iPhone / 真实账号执行仍待用户验证。

发布脚本已内置所需的公开 SDK 和通用代码，不需要另外安装源码或下载 SDK。
