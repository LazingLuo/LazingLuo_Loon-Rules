# 京东开屏处理与诊断

版本：2026-10-26.5。更新原来的 `Plugins/jd_open.plugin` 和 `Scripts/jd-splash.js`。

## 本次调整

- 图片只覆盖 `m.360buyimg.com/mobilecms/`。不再解密所有京东图片域名，也不再对其他CDN资源逐条读取素材记录。
- URL带 `s1125x2436_jfs/` 或 `s1125x1602_jfs/` 时，由拒绝规则直接处理，扩展名不限，不启动尺寸脚本。
- 上述目录内其余成功图片响应，才检查真实像素尺寸，避免文件地址不带尺寸时漏掉。PNG、JPEG、GIF、WebP、HEIC、AVIF支持不变；命中1125×2436或1125×1602后返回404和空正文，不再替换透明图片。
- 普通尺寸、其他竖图和无效图片直接通过，不读取或保存素材诊断。命中尺寸时才保存一条精简记录。两种尺寸均为原规则中的1125宽，未增加1136宽或其他猜测尺寸。
- 视频恢复原规则：直接拒绝 `storage.360buyimg.com/material-video/video/` 内MP4，不解析视频尺寸，不运行素材脚本。该路径规则可能覆盖同目录其他视频。
- 图片、视频全部静默处理。取消全CDN“已确认素材”动态查找，start素材映射仅用于诊断。

## 配置处理与通知

`start`、`basicConfig`、`welcomeHome`、`searchBoxWord` 的原有诊断保留。只对start中HTTP200、业务码0、images内完整有效日期对设为2000年的过期日期；其他配置继续只观察。

后台开屏通知只在start响应命中或开屏配置实际修改时出现。有日期改写显示“开屏配置已修改”，其他start显示“start 已命中”；一次响应只发一条。图片、视频及其他配置单纯命中均不通知。手动导出、清空操作仍提示操作结果。

## 使用与凭据

在Loon更新原插件和脚本缓存。停用旧的独立图片尺寸/素材视频规则，避免重复处理。插件继续放在京东活动和京东签到前面。

内置统一被动凭据获取不变，普通京东页面仍可保存Cookie、PLUS盲盒、刮卡、京喜、种豆和农场资料，金融域名由活动/签到插件处理。插件自身不发起签到或活动请求。

“导出京东开屏诊断记录”输出本机日志供分享；“清空”仅清除本插件诊断，不清除凭据或App缓存。start来源素材地址去掉查询参数和片段，只保存允许的京东CDN路径，不保存Cookie、账号、完整请求响应或密文。

## 性能与验证

图片二进制读取仍需等待完整响应，但仅限原mobilecms目录。其他图片不进入本插件尺寸脚本。静态拒绝规则的图片和视频不会计入脚本素材处理次数；旧版本素材计数保留。配置扫描的上限与诊断记录保留策略沿用上一版，不据此承诺全部加载开销消失。

80项离线检查通过，包括路径边界、两种尺寸、各图片格式、空404、图片零通知、静态视频拒绝、start通知以及PLUS等统一凭据兼容性。另通过3项Apple JavaScriptCore运行检查。未调用真实京东账号；手机速度和拦截效果待实际使用验证。

Response脚本允许返回状态码和空二进制正文，见[Loon Script API](https://nsloon.app/docs/Script/script_api/#115-修改响应)。同阶段首条脚本匹配语义见[Loon脚本说明](https://nsloon.app/docs/Script/script_v2/)。
