# 京东开屏处理与诊断

版本：2026-10-26.3。更新现有 `Plugins/jd_open.plugin` 和 `Scripts/jd-splash.js`。

## 使用

将本插件放在京东活动、京东签到插件前面。更新后它保留同一套被动凭据解析：普通京东页面仍会保存Cookie、PLUS盲盒、刮卡、京喜、种豆和农场的资料，不会因为开屏响应脚本先匹配就丢掉凭据。金融域名继续由活动/签到插件处理。手动签到、定时签到和活动执行入口不变。本插件自身不会发起任务或签到请求。

关闭旧的京东图片尺寸/素材视频重复规则，避免同一资源被两套规则处理。正常使用京东即可，不需要重装或同时抓HAR。需要分析时运行“导出京东开屏诊断记录”，分享本次日志；“清空”只清除本插件诊断及素材记录，不清除账号凭据或App缓存。

## 三部分行为

1. 配置处理：仅对start中HTTP200、业务码0、images内有效日期对设为2000年的过期日期，保留其他内容。welcomeHome、searchBoxWord的expireAds，以及basicConfig等开关保持原值。
2. 素材处理：默认继续使用1125×2436、1125×1602两个已有尺寸。读取PNG/JPEG/GIF/WebP/HEIC/AVIF响应的像素尺寸，命中后替换为透明1像素PNG；不再依赖特定目录和后缀。对于start素材列表确认过的主图片url和主视频videoUrl，后续下载会返回404阻止缓存；相同十六进制素材标识可覆盖其他CDN和格式变体。按钮、卡片、联动视频等辅助地址只保存，不凭辅助地址自动拦截。未确认的material-video目录MP4、大竖图只记录候选，其他图片保持原样。尺寸是经验条件，同尺寸正常图片仍可能被替换；遇到误伤可先停用“京东图片尺寸检查”。
3. 定向诊断：开屏相关分组优先扫描，使用独立预算；记录扫描是否完整及触及的限制。只找到部分信息时不会再提示“没有开屏字段”。仅保留目标开关、日期、expireAds、start素材groupId及其图片/视频地址映射，减少无关结构。

## 通知

仅实际修改日期或处理素材时通知。普通配置命中和候选素材只写本机记录，不弹通知。连续命中同一素材时，10分钟内合并通知；计数仍累计。手动导出/清空也会通知。

“图片已替换”表示按尺寸处理了图片，“确认素材已拦截”表示资源与start列表相符；二者都不等同于证明本次广告已经完全消失。透明替换可能保留广告容器或倒计时；已有App缓存和包内默认启动图不受网络拦截直接影响。

## 记录范围

- 四个接口独立统计请求/响应次数，保留最近3个摘要。
- 大配置优先检查JDApp-home、appConfig、extSwitch及Splash/Launch命名分组。正文上限2MB；目标扫描2万节点、普通扫描8千节点、深度24、配置字符串最多64条且总量1MB。结构路径记录达到120条，只标注结构摘要截断，不冒充扫描失败；实际扫描限制单独记录。
- start只从已确认的images结构采集素材。最多80条本机素材映射，样本最多40条。groupId不是图片文件名，也不是所有业务通用的开屏标记。
- 素材只保存允许的京东CDN主机与路径，去掉查询参数和片段；不保存请求头、Cookie、账号、完整响应或密文。辅助素材不会自动升级为拦截规则。
- 素材事件保留最近30条。总存储上限192K字符，超限时收缩旧摘要。保留旧版四接口计数和诊断记录。
- 旧版输出的“未找到字段”若同时limited=true，只能解释为部分扫描结果；新版新增limitReasons。

脚本不会上传诊断。发布包仅含通用代码、说明和合成数据检查，不含用户抓包、IPA或导出记录。已验证通过的签到凭据仍仅保存在本机原有独立键下。

## 验证边界

离线模拟检查配置优先扫描、日期处理、素材关联、六种图片格式、误伤边界、仅实际动作通知、凭据获取透传和已移除活动无入口。系统JavaScriptCore运行检查另行执行。未向真实京东账号发起测试请求，手机实际效果待验证。

Loon每个阶段只选择首个匹配脚本，且规则条件暂不支持请求正文筛选，见[官方脚本规则说明](https://nsloon.app/docs/Script/script_v2/)。因此本版内置被动凭据解析并要求开屏插件优先；不能假设脚本原样返回后还会继续执行下一条响应脚本。
