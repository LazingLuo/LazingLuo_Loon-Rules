# 京东开屏处理与诊断

版本：2026-10-29.1。

- 图片只按 URL 拦截：`m.360buyimg.com/mobilecms/` 下的 `s1125x2436_jfs/`、`s1125x1602_jfs/` 两种尺寸路径直接拒绝，扩展名不限。
- 删除图片响应脚本和实际尺寸解析。地址不带上述尺寸路径的图片直接通过，即使实际尺寸相同也不处理。
- 视频沿用 `storage.360buyimg.com/material-video/video/` 内 MP4 的静态拒绝规则。
- 图片、视频均不运行素材脚本，不发通知，不新增素材处理计数。旧诊断记录保留。
- `start` 日期过期处理、定向配置诊断和统一凭据获取保持不变。后台开屏通知只在 `start` 响应命中或配置实际修改时出现。

在 Loon 更新原 `jd_open.plugin` 及脚本缓存。必须更新插件，才能移除旧图片响应规则。插件继续放在京东活动和签到插件前面；如曾单独安装图片尺寸检查规则，也应停用。

手动导出仅输出本机诊断日志，清空仅清除本插件诊断，不清除凭据或 App 缓存。当前版本无需等待图片正文来判断实际尺寸；HTTPS URL 匹配仍需 MitM。
