# 闲鱼开屏净化（静态分析验证版）

版本：2026-10-25.1。根据用户提供的闲鱼 7.28.70 / 59243297 IPA 静态分析制作。

## 相比现有版

- 保留两个精确接口和 `acs.m.goofish.com` 的限定，不增加 HTTPDNS 屏蔽或 UDP 限制。
- 继续清空 `adMap` 和 `dspList`。
- 增加清理 `realTimeAd`：它是独立的可选实时广告字段，旧版未处理。
- 主接口将 `hotStartInterval` 改为 315360000 秒，约十年。App 普通前后台切换入口会比较后台停留时间与该间隔。已有数字/字符串保持各自类型。
- 主接口缺少列表时补为空列表，避免“字段缺省”保留旧配置/默认广告来源。异步接口保持部分更新，不补主接口字段。
- 通知分别列出实际操作，例如“已移除实时广告”“已延长热启动间隔”。广告本来为空也可能需要调整间隔，因此不把这次操作称为“清除了广告”。

## 使用和验证边界

发布文件为 `Plugins/xianyu_open.plugin`、`Scripts/idle-splash.js`、`Tests/idle-splash.test.cjs` 和本说明。插件沿用已有入口，脚本版本参数为 `v=20261025-1`。在 Loon 更新插件及脚本缓存后保存、重连。尚未在手机上验证实际去开屏效果。

以后测试时应替换旧版，避免相同接口的响应脚本互相覆盖。无需再次卸载闲鱼。关闭插件停止后续改写，但 App 已接收的间隔配置可能保留到再次收到原始响应；关闭插件后正常使用，让后续主接口刷新即可观察恢复，不能承诺立即复原。

这次未改 Orange 开关。已定位 `splash_ad.disableHotStartAd` 及第三方开关，但没有该组配置的可读网络响应样本。单靠它们的代码名称不能保证 Loon 能改到。

未删除设备里已下载的素材或第三方 SDK 私有缓存；预览、分享唤起等特殊分支不保证受普通热启动间隔约束；独立加密通道中的请求仍可能绕过当前改写入口。

检查：在仓库目录运行 `node Tests/idle-splash.test.cjs`；本地同目录可以运行 `node test.cjs`。45 个离线场景和 3 个 Apple JavaScriptCore 运行场景通过。检查只验证离线 JSON 改写和保护条件，不证明真实设备已经消除开屏。IPA 和 HAR 仅保留本地，脚本不读取账号凭据，也不主动发请求。
