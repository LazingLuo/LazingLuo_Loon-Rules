# 闲鱼开屏净化（静态分析验证版）

版本：2026-11-20.1。复核闲鱼 7.29.11 IPA 的开屏调用与 Swift 数据模型。

## 相比现有版

- 两个精确开屏接口增加 `acs.wapa.goofish.com` 和 `acs.m.taobao.com` 网关候选；三个网关只匹配闲鱼开屏接口名和对应版本。候选网关来自 IPA，尚无该请求在候选网关上的实机命中记录。
- 继续清空 `adMap` 和 `dspList`。
- 继续清理 `realTimeAd`。主接口和异步接口收到可选的 `cacheAdInfo` 对象时置空；`spaceIdMap` 只移除模型确认的优量汇（`ylh`）和聚合广告（`adPlus`）开屏广告位，保留其他键。
- 主接口将 `hotStartInterval` 改为 315360000 秒，约十年。App 普通前后台切换入口会比较后台停留时间与该间隔。已有数字/字符串保持各自类型。
- 主接口缺少列表时补为空列表，避免“字段缺省”保留旧配置/默认广告来源。异步接口保持部分更新，不补主接口字段。
- 通知分别列出实际操作，例如“已移除实时广告”“已延长热启动间隔”。广告本来为空也可能需要调整间隔，因此不把这次操作称为“清除了广告”。

## 使用和验证边界

发布文件为 `Plugins/xianyu_open.plugin`、`Scripts/idle-splash.js`、`Tests/idle-splash.test.cjs` 和本说明。插件沿用已有入口，脚本版本参数为 `v=20261120-1`。在 Loon 刷新订阅后验证。新增处理尚未在手机上验证。

以后测试时应替换旧版，避免相同接口的响应脚本互相覆盖。无需再次卸载闲鱼。关闭插件停止后续改写，但 App 已接收的间隔配置可能保留到再次收到原始响应；关闭插件后正常使用，让后续主接口刷新即可观察恢复，不能承诺立即复原。

这次未改 Orange 开关。已定位 `splash_ad.disableHotStartAd` 及第三方开关，但没有该组配置的可读网络响应样本。单靠它们的代码名称不能保证 Loon 能改到。

未删除设备里已下载的素材或第三方 SDK 私有缓存；预览、分享唤起等特殊分支不保证受普通热启动间隔约束；独立加密通道中的请求仍可能绕过当前改写入口。

检查：在仓库目录运行 `node Tests/idle-splash.test.cjs`。检查只验证离线改写及匹配范围。IPA 和 HAR 仅保留本地，脚本不读取账号凭据，也不主动发请求。
