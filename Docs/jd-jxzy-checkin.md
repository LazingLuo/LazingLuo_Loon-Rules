# 京喜自营每日签到

这是独立插件，不加入京东三合一、种豆或金融插件。只处理京喜自营店的每日签到；不做分享助力、额外任务或其他领取入口。

## 安装与首次使用

安装 `Plugins/jd-jxzy-checkin.plugin`。

1. 开启“获取京喜凭据”，进入京东 App 的京喜自营店页面，等待签到区域加载。
2. 收到“凭据已保存”通知后，关闭获取开关。今天已经签到也可获取，无须再次领取。
3. 在 Loon 执行“京喜自营手动签到”，查看结果。已签到时只查询，不重复领取。
4. 手机端验证后开启“自动签到”。若今天已经签到，尚需下一次实际领取验证完整自动领取流程。

查询请求本身不含 h5st，首次还需要同一页面的签名环境。插件会从该页活动查询或签到请求获取；若未收到完整保存通知，可退出页面重新进入并等待加载。凭据不从其他签到插件导入。

## 定时与刷新

自动签到默认关闭；默认签到时间每天00:00，之后随机等待0–1200秒。最小、最大随机秒数均可设为0–2000的整数；设为相同数值表示固定等待。等待期间不持执行锁，手动签到立即执行。自动执行在等待结束后读取最新凭据。

“京喜页面刷新凭据”默认开启：再次进入这个京喜自营页面时，刷新本插件已有的同账号查询模板、页面环境和登录凭据。它只监听京喜自己的三个活动接口，不监听首页、购物车等全站接口；不会创建新账号记录，也不会修改其他签到插件的数据。首次获取或更换账号仍需开启“获取京喜凭据”。

## 结果与日志

每次先查询；未签到且状态明确时领取一次，再查询确认。已签到直接报告。提交前保存当天账号记录；网络超时、返回异常或复查未确认，不自动重复提交，需在活动页查看实际结果。状态不明确时记录状态摘要，不猜测已签到。

通知显示获得的京豆或优惠券，以及本轮第几天。当前抓包是三天一轮，第1、2、3天配置分别为1、2、4京豆；实际奖励以接口结果为准，不把页面总金额或助力金额当作本次签到奖励。

“京喜自营签到最近结果”只读本地，不请求京东、不触发领取。独立存储键：

- `JXZY_CHECKIN_ACCOUNT_V1`：本插件凭据，含敏感登录信息，仅保留在 Loon 本机。
- `JXZY_CHECKIN_LAST_RESULT_V1`：最近结果。
- `JXZY_CHECKIN_HISTORY_V1`：最近30次执行历史。
- `JXZY_CHECKIN_LOCK_V1`：执行锁。
- `JXZY_CHECKIN_ATTEMPT_V1`：当天领取提交记录。
- `JXZY_CHECKIN_SDK_V1`：本插件独立的签名缓存。

脚本不读取或写入其他签到插件的键；结果和通知不包含Cookie、设备令牌或完整响应。无固定七天过期规则，登录是否有效以接口实际返回为准。

## 验证范围

已对360抓包完成离线分析：查询未签、领取1京豆、复查已签的链条完整。公开前端的 signStr 规则能复现包内8次活动请求；h5st 签名字段、版本及环境一致性已离线核对。使用本地模拟接口验证了签到、已签跳过、失败停止、重复提交保护、独立存储、参数刷新、秒级随机等待、手动与定时交错、本地结果读取等情况。

仅签名的纯函数在构建时复用经过核对的官方代码；发布脚本已完整内嵌，运行时不依赖安装其他插件。未使用抓包中的凭据向京东发送请求，首次自动领取仍需手机端验证。
